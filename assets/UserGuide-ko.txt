SidePad 1.12 사용 안내

[아이폰 화면 미러링]
1. Android 9 이상 패드에 SidePad.apk를 설치합니다.
2. 아이폰과 패드를 같은 Wi-Fi에 연결합니다.
3. 패드에서 SidePad를 열고 ‘아이폰 화면 미러링’을 선택합니다.
4. 아이폰 제어 센터 → 화면 미러링 → ‘SidePad · 패드 모델명’을 선택합니다.
5. 아이폰이 비밀번호를 요구하면 패드의 4자리 연결 코드를 입력합니다.
6. 패드 앱을 나가면 수신이 중지됩니다. 앱 아이콘으로 열면 연결 방식을 다시 선택합니다.
아이폰에 SidePad 앱을 설치하거나 Android USB 디버깅을 켤 필요가 없습니다.
게스트 Wi-Fi의 기기 간 통신 차단, 공유기의 멀티캐스트 차단 등은 검색을 방해할 수 있습니다.

[Mac USB 모니터]
1. Apple Silicon Mac / macOS 14 이상에서 ZIP의 SidePad.app을 응용 프로그램 폴더에 설치합니다.
2. 처음 실행 안내.html에 따라 실행 승인과 화면 기록 권한을 허용합니다.
3. 데이터 USB 케이블로 Android 패드를 연결하고, 패드의 USB 디버깅과 Mac 연결 승인을 허용합니다.
4. Mac 앱에서 연결 시작을 누르거나 패드에서 Mac USB 모니터를 선택합니다.
5. 해상도 메뉴의 Retina 2×는 실제 픽셀을 유지하면서 글자와 작업 공간을 크게 표시합니다.
Mac 앱의 펜·터치 입력에는 손쉬운 사용 권한이 필요합니다.

[AirPlay 미리보기 기능의 검증 범위]
AirPlay는 iPhone 15 Pro와 Lenovo TB373FU에서 화면·소리 및 수정 후 회전을 확인했습니다.
다른 기종과 장시간 안정성, 보호된 영상은 검증하지 않았습니다.
HLS 영상 URL 재생, 패드 터치로 아이폰 조작은 지원하지 않습니다.
패드 내부 지연 측정은 전체 입력→화면 지연과 다릅니다.

[업데이트]
1.12 정식 배포는 Mac 앱의 업데이트 확인 → 업데이트 설치에서 받을 수 있습니다.
Android는 기존 앱을 삭제하지 않고 최신 APK를 설치합니다.
