SidePad 1.11 · 사이드패드

Android 패드를 USB-C로 Mac의 확장 모니터로 사용합니다.

설치
1. Mac에 ADB를 설치합니다. Homebrew 사용자는 brew install --cask android-platform-tools를 실행합니다.
2. 패드의 개발자 옵션에서 USB 디버깅을 켜고, USB 연결 후 이 Mac의 디버깅 요청을 허용합니다.
3. SidePad-macOS.zip을 풀고 SidePad.app을 응용 프로그램 폴더로 옮겨 실행합니다. Android 앱은 Mac 앱에 포함되어 있어 자동 설치·업데이트됩니다.
4. Android 앱만 직접 설치할 때는 SidePad.apk를 패드에서 열어 설치합니다. 패드 앱만으로 연결이 완성되지 않으므로 Mac 앱도 실행해야 합니다.
5. Mac에서 화면 및 시스템 오디오 녹음 권한을 허용합니다. 터치·펜을 사용하려면 손쉬운 사용 권한도 허용합니다.

처음 실행 승인
- ‘SidePad을(를) 열지 않음’ 경고에서 완료를 누릅니다.
- 함께 들어 있는 ‘실행 승인 설정 열기.webloc’을 열면 개인정보 보호 및 보안으로 이동합니다.
- 아래쪽 보안에서 SidePad의 ‘그래도 열기’를 누르고, 이어지는 열기·인증을 진행합니다.
- 바로가기가 열리지 않으면  → 시스템 설정 → 개인정보 보호 및 보안 → 보안으로 이동합니다.
- 자세한 순서는 ‘처음 실행 안내.html’과 앱의 ‘설치·권한 안내’ 메뉴에 있습니다.
- 실제 실행 승인은 사용자가 직접 선택합니다.

USB 디버깅
Mac 앱만 설치해도 Android 앱은 자동 설치됩니다. 두 앱을 직접 설치한 경우에도 USB 디버깅은 필요합니다.
현재 USB 전송은 ADB를 사용하므로 개발자 옵션·USB 디버깅 없이 연결하는 기능은 없습니다.
자동 설정은 패드의 실제 해상도·화면 비율과 하드웨어 디코더 지원 모드를 읽어 선택합니다. 자동 설치와 실제 기종별 성능 검증은 별개입니다.

재연결과 업데이트
- 패드에서 홈 화면이나 다른 앱으로 이동하면 화면·소리·입력 전송을 멈추고 가상 모니터를 해제합니다.
- Mac 앱과 USB 연결을 유지한 상태에서 패드의 SidePad를 다시 열면 기존 연결 정보·해상도·프레임 속도·소리 출력·모니터 배열로 다시 연결됩니다.
- Mac이 패드 앱을 강제로 다시 실행하지 않습니다. Mac의 연결 시작을 누르면 직접 다시 열 수 있습니다.
- 실행 시와 6시간마다 새 버전을 자동 확인하고, 앱 버튼과 SidePad 메뉴에 ‘업데이트 가능 · 버전’을 표시합니다. 자동 확인은 팝업을 띄우지 않습니다.
- 업데이트 가능 또는 업데이트 확인 → 업데이트 설치로 다운로드·검증·설치·재실행합니다. 나중에를 누르면 업데이트 가능 표시를 유지합니다. 연결된 패드 앱도 함께 업데이트됩니다.
- 앱과 앱이 있는 폴더에 쓰기 권한이 필요하며, 인터넷으로 공식 GitHub 정식 배포를 확인합니다.
- 화면 기록 승인이 켜져 있는데도 연결되지 않으면 SidePad 메뉴의 화면 기록 승인 복구 → 승인 다시 등록을 사용하세요. SidePad의 화면 기록 승인만 초기화합니다.
- 새 SidePad를 시스템 설정에서 허용하고 앱을 종료했다가 다시 여세요. 펜·터치는 손쉬운 사용 권한을 별도로 허용하세요.

사용
- 자동 · 패드에 맞게: 요청한 60/30fps에서 지원하는 가장 큰 화면을 선택합니다. 60fps를 지원하지 않으면 30fps를 사용합니다.
- 해상도 메뉴: 패드를 한 번 연결하면 ‘2944 × 1840 · Retina · 원본’처럼 지원하는 해상도를 직접 선택할 수 있습니다. 연결 중 선택하면 잠시 재연결해 적용하며 다음에도 기억합니다.
- 처음 연결 전에는 자동·원본 우선·균형·가볍게를 표시합니다. 다른 패드에 저장 해상도가 없으면 자동으로 선택합니다.
- Retina (2×): 폭 2000픽셀을 넘는 확장 화면. 예: 실제 픽셀 2944 × 1840 / 화면 크기 1472 × 920. 글자를 크게 유지하면서 픽셀을 촘촘하게 표시합니다.
- 일반 (1×): 전송 픽셀과 작업 공간 크기가 같습니다. 화면 복제는 Mac 주 화면의 글자 크기를 따릅니다.
- 화면 모드와 영상 프레임 속도는 중지 → 옵션 선택 → 연결 시작 순서로 변경합니다.
- 패드의 첫 화면 렌더링 응답을 받은 뒤 연결됨으로 표시합니다. 디코더 오류와 USB 승인 대기를 구분해 안내합니다.
- 표시 fps, 패드 디코딩 시간, USB 왕복 시간을 따로 표시합니다. 전체 입력 지연을 뜻하지 않으며 정지 화면의 fps는 낮아집니다.
- 혼잡이 지속되면 비트레이트를 조절하고, 연결이 없을 때는 커서 검사 타이머를 멈춥니다.
- 지원 패널·커서는 최대 120Hz, 영상은 최대 60fps.
- 커서는 영상과 별도로 전송하고 밀린 위치는 최신 좌표로 합칩니다. 같은 모양의 중복 전송과 표시 레이어 재생성을 줄였습니다.
- 손가락: 탭=클릭, 더블 탭=더블 클릭, 한 손가락 이동=드래그, 두 손가락 이동=스크롤.
- 펜: 클릭·드래그·필압·기울기를 전달합니다. 옆 버튼을 누르고 접촉하면 오른쪽 클릭입니다.
- 펜이 화면에 닿거나 호버하면 손가락 입력을 억제합니다. 펜을 화면에서 충분히 떼고 약 0.6초 후 터치할 수 있습니다.
- 소리 출력 메뉴: Mac + 패드(기본), 패드만, Mac만. 메뉴 막대의 SidePad에서도 선택할 수 있습니다.
- 패드 음량은 패드 볼륨 버튼으로 조절합니다. 마이크가 아닌 Mac에서 재생되는 소리를 전달합니다.
- 패드만 모드에서는 Mac을 음소거하며, 다른 모드·연결 해제·종료 시 이전 상태를 복원합니다.
- 모니터 위치와 주 모니터를 패드별로 기억합니다. 같은 모니터 구성·해상도에서는 재연결 때 마지막 배열을 복원합니다.
- 이미 실행 중인 앱을 다시 열면 기존 앱을 활성화합니다.
- 창을 닫아도 전송됩니다. 메뉴 막대의 SidePad → 종료로 종료합니다.

알아둘 점
개발용 서명으로 빌드되어 Apple 공증은 받지 않았습니다. Mac에서 내려받은 앱을 열 때 시스템의 일반 앱 허용 절차를 따르세요.
Mac 배포 앱은 Apple Silicon용입니다. Android의 지원 모드 보고와 실제 처리 속도는 다를 수 있으며 다른 기종의 성능은 별도 검증이 필요합니다.
영상은 최대 60fps이며 실제 속도와 지연은 장면과 부하에 따라 달라집니다. USB 왕복 수치는 전체 화면 지연이 아닙니다.
필압 효과는 대상 앱의 설정과 지원 여부에 따라 달라집니다. 손가락 확대·축소는 아직 지원하지 않습니다.
