처음 실행이 막혔나요?

현재 배포판은 Apple 공증을 받지 않아, 처음 실행할 때 macOS의 승인이 필요할 수 있습니다. 공식 SidePad 배포판인지 확인한 뒤 아래 순서로 진행하세요.

  1. SidePad.app을 한 번 여세요.
    ‘SidePad을(를) 열지 않음’ 경고가 나오면 완료를 누르세요.
  2. 개인정보 보호 및 보안으로 이동하세요.
    아래 버튼을 누르거나, 함께 들어 있는 실행 승인 설정 열기.webloc 파일을 여세요.
  3. 보안 항목에서 SidePad의 ‘그래도 열기’를 누르세요.
    아래로 스크롤해야 할 수 있습니다. 이어지는 확인 창에서 열기를 선택하고, Mac에서 요청하는 인증을 완료하세요.
실행 승인 설정 열기
버튼이 열리지 않으면  → 시스템 설정 → 개인정보 보호 및 보안 → 보안으로 이동하세요. ‘그래도 열기’가 없으면 SidePad.app을 다시 열어 경고를 확인한 직후 설정을 다시 확인하세요. 이 안내와 바로가기는 설정 화면만 열며, 실행 승인은 사용자가 직접 선택합니다.

실행한 다음에는

패드의 개발자 옵션 → USB 디버깅을 켜고 USB-C로 연결하세요. Mac 앱에 Android 앱이 포함되어 자동 설치됩니다. Android APK를 직접 설치해도 USB 디버깅은 필요합니다.

화면 권한 버튼에서 ‘화면 및 시스템 오디오 녹음’을 허용하세요. 터치와 펜을 쓰려면 펜·터치 권한 버튼에서 ‘손쉬운 사용’도 허용하세요.

화면 기록이 켜져 있는데 연결되지 않으면 SidePad → 화면 기록 승인 복구…에서 이전 승인을 다시 등록하고, 허용 후 앱을 다시 여세요.

다시 연결하기와 업데이트

패드에서 다른 앱으로 이동하면 전송을 멈춥니다. Mac 앱과 USB 연결을 유지한 상태에서 패드의 SidePad를 다시 열면 기존 설정과 모니터 배열로 연결됩니다.

새 버전은 Mac 앱의 업데이트 확인 → 업데이트 설치로 적용합니다. Mac 앱을 다시 열고 연결된 패드 앱도 함께 업데이트합니다.

이 안내는 앱의 SidePad → 설치·권한 안내 메뉴에서 다시 볼 수 있습니다.
