[업데이트] 안드로이드 패드로 아이폰 화면도 볼 수 있게 만들었습니다 — SidePad

안녕하세요. 안드로이드 패드를 Mac의 보조 모니터로 사용하는 앱, SidePad를 만들고 있습니다.
이번에는 아이폰 화면을 패드에서 볼 수 있는 AirPlay 미러링 기능을 추가했습니다.

아이폰에는 별도 앱을 설치할 필요가 없습니다.
아이폰과 패드를 같은 Wi-Fi에 연결한 뒤, 아이폰의 기본 ‘화면 미러링’ 메뉴에서 패드를 선택하는 방식입니다. 이 기능은 Mac 없이 두 기기만으로 사용할 수 있습니다.

이번에 추가한 내용
• 앱을 열면 ‘Mac USB 모니터 / 아이폰 화면 미러링’을 먼저 선택합니다.
• 아이폰 화면과 소리를 안드로이드 패드로 받을 수 있습니다.
• 패드에 표시되는 4자리 코드로 연결합니다.
• 패드에서 앱을 나가면 미러링 수신을 중지합니다.
• 기존 Mac USB 확장 모니터 기능도 함께 사용할 수 있습니다.

아이폰 연결 방법
1. 아이폰과 패드를 같은 Wi-Fi에 연결합니다.
2. 패드에서 SidePad → ‘아이폰 화면 미러링’을 선택합니다.
3. 아이폰 제어 센터 → ‘화면 미러링’ → ‘SidePad · 패드 모델명’을 선택합니다.
4. 비밀번호를 물어보면 패드에 표시된 4자리 코드를 입력합니다.

아이폰 미러링 모드에서는 패드의 개발자 옵션이나 USB 디버깅을 켤 필요가 없습니다. 기존 Mac USB 모드에서는 USB 디버깅 설정이 필요합니다.

현재 아이폰 15 Pro와 Lenovo Idea Tab Pro에서 화면·소리 수신을 확인했습니다. AirPlay 기능은 아직 미리보기 단계이며, 화면 회전 시 영상 복귀와 지연을 계속 다듬고 있습니다. 모든 안드로이드 패드에서 검증한 것은 아니어서 기종과 Wi-Fi 환경에 따라 차이가 있을 수 있습니다.
